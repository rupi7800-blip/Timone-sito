Dove stanno i tuoi dati

Dipende da come usi Timone. Qui sotto trovi cosa succede in ogni caso, compresi i limiti.

Sul tuo dispositivo (predefinito)

  • Non serve nessuna registrazione: i dati stanno nel browser del tuo dispositivo.
  • Niente password né cifratura.
  • Nessuna copia automatica.
  • Se cancelli i dati del browser, li perdi.
  • Puoi esportare copie in formato JSON (un file con tutti i dati dell'azienda). I file esportati vanno protetti da te. Da verificare sulla versione pubblicata.

Database su un servizio in rete o sul server dell'azienda (Supabase)

In preparazione. È previsto, ma il collegamento non è ancora stato provato su un progetto reale.

Non è ancora provato che ogni utente veda solo i dati che gli spettano.

Se attivi un servizio AI

  • Nessun servizio è attivo in partenza.
  • Quando fai una richiesta, i dati dell'azienda e le tue domande vanno al servizio che hai scelto.
  • Con il passaggio automatico, se un servizio fallisce la stessa richiesta può andare a un altro tra quelli attivi.
  • Alcuni piani gratuiti possono usare i dati inviati.
  • Non c'è anonimizzazione.
  • Le chiavi di accesso sono salvate nel browser, senza cifratura.

Componenti esterni

  • Per leggere i file Excel l'app scarica il lettore SheetJS da cdn.sheetjs.com (la lettura dei file Excel non è ancora provata).
  • In modalità database l'app scarica la libreria Supabase da cdn.jsdelivr.net.

Quei servizi ricevono i normali dati tecnici di connessione, come l'indirizzo IP.

Questa pagina descrive l'app Timone, non questo sito: il sito non raccoglie dati (vedi Riservatezza).
